# 🎮 MapleQuest RPG

메이플스토리 스타일의 2D 횡스크롤 RPG 브라우저 게임

**언어:** Vanilla JavaScript (ES6+ Modules)
**렌더링:** HTML5 Canvas
**의존성:** 없음 (순수 바닐라)
**버전:** 2.0 - 도메인 기반 아키텍처

---

## 🚀 빠른 시작

### 게임 실행
```bash
# Windows
cd game
python -m http.server 8000
start "" "http://localhost:8000/public"

# 또는 스크립트 사용
scripts\server.bat
```

### 브라우저에서 열기
```
http://localhost:8000/public/index.html
```

## 🎯 주요 기능

### 핵심 시스템
- ✅ **3개 직업**: 전사 ⚔️, 도적 🗡️, 궁수 🏹
- ✅ **전직 시스템**: Lv10/30/70 단계별 전직 (초변직 구현 완료)
- ✅ **12개 스킬/직업**: 기본 3개 + 초변직 3개 (재변직·최종변직 추가 예정)
- ✅ **전투 시스템**: 크리티컬, 넉백, 콤보, 백스탭
- ✅ **성장 시스템**: 레벨업, 스탯 증가, 경험치 스케일링

### UI/UX (메이플스토리 스타일)
- ✅ **HUD**: HP/MP/EXP 바, 스탯 표시, 미니맵
- ✅ **스킬바**: 원형 쿨다운 진행바, 애니메이션
- ✅ **전투 피드백**: 대미지 텍스트, 콤보, EXP 획득, 메소 드랍
- ✅ **이펙트**: 화면 흔들림, 히트스톱, 크리티컬 이펙트, 레벨업 빛기둥

### 추가 시스템
- ✅ **퀘스트 시스템**: 퀘스트 추적기, 보상 시스템
- ✅ **업적 시스템**: 도전 과제, 보상 획득
- ✅ **상점 시스템**: 아이템 구매/판매
- ✅ **스탯 화면**: 상세 스탯 조회
- ✅ **게임 오버/일시정지**: 완전한 게임 플로우

### 개발자 도구
- ✅ **개발자 치트**: 콘솔에서 `setLevel(n)` 사용 가능
- ✅ **테스트 자동화**: 42개 통합 테스트

## 🛠️ 개발자 치트

브라우저 콘솔(F12)에서 사용 가능:
```javascript
setLevel(9)              // 레벨 설정 (경험치 자동 조정)
player.hp = player.maxHp // HP 완전 회복
player.mp = player.maxMp // MP 완전 회복
```
